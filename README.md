# 慢慢來

免登入的自我照顧工具頁，手機和電腦都能使用。

網站：<https://clchrf.github.io/slow-down/>

## 功能

呼吸、54321 著陸、身體放鬆、伸展、背景聲、計時、互動光點、隨機任務、影片、筆記與備忘。使用說明在右上角 **i**。

## 資料

- 筆記與備忘存在各自的瀏覽器，可在 **i** 匯出或匯入備份。
- 影片存在各自的瀏覽器，重開網站仍可使用；備份檔不包含影片。
- 任務照片只在當次頁面有效。資料不會上傳；清除網站資料會移除筆記、備忘與影片。

## 本機預覽

執行 `python -m http.server 8000`，開啟 <http://localhost:8000/>。

網站由 GitHub Pages 從 `main` 分支自動發布。
