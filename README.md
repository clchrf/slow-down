# 慢慢來｜心情急救包

有時候腦袋很吵，或是身體有點緊，只想先停一下。

這是我做的一個小工具頁。你可以打開來呼吸、放鬆、寫幾句話，也可以什麼都不急著做，先待一下就好。手機和電腦都能用，不用登入。

網站在這裡：<https://clchrf.github.io/slow-down/>

## 裡面有什麼

- 想讓自己慢一點：呼吸練習、54321 著陸、身體放鬆、伸展、左右注意力和互動光點。
- 想安靜一下：背景聲、3 分鐘計時、睡前整理，還有一些小提醒。
- 想把事情寫下來：筆記、備忘和整理思緒。
- 不知道現在能做什麼：可以抽一個小任務，不想做就換一個。
- 想看自己的影片：可以加好幾段，左右滑著選，點開後可以放大、循環或全螢幕播放。

不知道怎麼用的話，點右上角的 **i** 就有說明。

## 本機預覽

在本目錄執行 `python -m http.server 8000`，再開啟 `http://localhost:8000/`。

## 關於你的資料

- 筆記和備忘只存在你現在用的瀏覽器，不會跟別人共用，也不會同步到別的裝置。
- 右上角的 **i** 可以匯出或匯入筆記與備忘。備份檔只會下載到你的裝置，不包含影片。
- 加入的影片也只存在這個瀏覽器。關掉再打開網站，通常還會在；你也可以自己移除。影片不會上傳。
- 任務照片只在這次開著的頁面顯示，重新整理或關掉頁面就沒有了，也不會上傳。
- 如果清除網站資料，筆記、備忘和影片都會消失。用無痕模式或瀏覽器空間不足時，影片也可能留不住。

背景聲由瀏覽器即時產生，網站沒有使用外部追蹤服務。

## 部署

GitHub Pages 已設定從 `main` 分支的儲存庫根目錄發布。推送更新到 `main` 後，網站會自動重新發布。

Vercel 匯入此 GitHub 儲存庫後，選擇 **Other** 框架，根目錄維持預設值；不需要建置指令或環境變數。之後推送到連接的 GitHub 分支即可自動重新部署。
