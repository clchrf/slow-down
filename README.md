# 慢慢來｜心情急救包

給想暫停一下、照顧自己的人，一個安靜的小工具頁。打開網站就能跟著呼吸、放鬆身體、整理思緒，或挑一件此刻做得到的小事。介面採用米白與灰藍配色，手機和電腦都能使用，無需註冊或登入。

**立即使用：** <https://clchrf.github.io/slow-down/>

## 可以做什麼

- **緩和當下：**呼吸練習、54321 著陸、身體放鬆、坐姿伸展、左右注意力與互動光點。
- **留一點空間：**背景聲、3 分鐘計時、睡前整理、提醒文字與基本照顧清單。
- **記下想法：**整理思緒、筆記與備忘。
- **換個步調：**依照當下狀態抽取隨機任務，也可以為任務暫時加入照片。
- **觀看自己的影片：**一次加入多段影片，左右滑動選擇，點開後可循環或全螢幕播放。

右上角的 **i** 有各項功能的使用說明。

## 本機預覽

在本目錄執行 `python -m http.server 8000`，再開啟 `http://localhost:8000/`。

## 資料與隱私

- 筆記與備忘以 `localStorage` 存在使用者自己的瀏覽器，不跨裝置或使用者同步。清除網站資料會移除紀錄。
- 加入的影片保存在各使用者自己的瀏覽器 IndexedDB，重開網站仍可播放；不會上傳或與其他使用者共用。可從影片卡片移除。瀏覽器清除網站資料、私密瀏覽結束或儲存空間不足時，影片可能消失。
- 任務照片使用暫時的物件網址，只在當次頁面有效，不會上傳。
- 背景聲由瀏覽器即時產生；網站沒有外部資源或追蹤服務。

## 部署

GitHub Pages 已設定從 `main` 分支的儲存庫根目錄發布。推送更新到 `main` 後，網站會自動重新發布。

Vercel 匯入此 GitHub 儲存庫後，選擇 **Other** 框架，根目錄維持預設值；不需要建置指令或環境變數。之後推送到連接的 GitHub 分支即可自動重新部署。
